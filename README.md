# lucid-binder-kit

Software engineer working on systems and applications primarily with Rust, my go-to language for writing reliable and high-quality programs.

日常脚本的集中地

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/lucid-binder-kit.git
cd lucid-binder-kit
chmod +x run.sh
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。
